# Hand-written knowledge that steers tools/disasm.py.
#   code <bank>:<addr>                 a code entry point
#   jumpvec <bank>:<addr> <n>          n consecutive "jp nn" vectors
#   wordtable <bank>:<addr> <n> [ctx]  n code pointers (ctx = slot-2 bank they assume)
#   fartable <bank>:<addr> <n>         n entries of (bank byte, code pointer)
#   name <bank>:<addr> <label>         give a label a real name
# Addresses are CPU addresses as mapped (bank 0 $0000, bank 1 $4000, others $8000).
